# LoomGuard

Fabric inspection from defect-free images only: PatchCore and Reverse Distillation, heatmap, defect list and a roll-level
quality grade. Source, documents and licences: the LoomGuard repository. Sample images are from RAW-FABRID (CC BY 4.0);
credits are shown under each image in the app.

Copy this file to `README.md` in the Space repository (the front matter above is what Hugging Face reads).
Model bundles are downloaded on first use from the Hub repository named in `assets/profiles.json`
or in the Space variable `LOOMGUARD_HUB_REPO`.
